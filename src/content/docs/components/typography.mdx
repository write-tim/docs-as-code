While specialized components add interactive flair to technical documentation, clean typography and standard Markdown form the bedrock of any readable knowledge base. Starlight applies an opinionated, highly legible typographic scale optimized for technical content.

<Aside type="tip">
Always rely on standard Markdown formatting for primary text before reaching for complex custom components. Clean text paired with proper headings ensures maximum accessibility for screen readers.
</Aside>
