The `<Steps>` component is used to guide users through sequential tasks. It visually elevates standard numbered lists with styled circular indicators and a connecting vertical timeline line, making complex workflows easier to track.

<Aside type="tip" title="When to use Steps">
Use the `<Steps>` component only when **order is strictly required** to complete a task successfully (e.g., software installation, account configuration). For lists where the order does not matter, use standard unordered bullet points.
</Aside>

## How to Write Procedural Steps

When guiding users through sequential workflows, break actions down into numbered steps:

<Steps>
1. **Import the Component:** Add `import { Steps } from '@astrojs/starlight/components';` to your frontmatter imports.
2. **Wrap Your List:** Enclose a standard numbered markdown list inside the `<Steps>` component tags.
3. **Highlight Key Actions:** Bold the first few words of each step to anchor the reader's eye.
</Steps>

## Technical Writing Guidelines

When drafting procedures for this knowledge base, adhere to the following stylistic rules:

* **Start with an imperative verb:** Each step should begin with an action word (e.g., *Click*, *Enter*, *Select*).
* **Bold UI elements:** If a user needs to interact with a specific button, menu, or text field, bold its name (e.g., Click **Save Settings**).
* **Keep steps atomic:** A single step should ideally represent a single user action. If a step contains more than two actions, break it down.
* **Format sub-steps as bullets:** If a step requires minor sub-actions or context (like Step 1 and 2 in the specimen above), use an indented unordered list.
