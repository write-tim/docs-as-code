The `<Aside>` component (often referred to as an admonition or callout) is used to draw attention to supplementary information, warnings, or helpful shortcuts without disrupting the main narrative flow of the document.

## How to Write Asides

Use asides to call out critical notes, warnings, or tips without disrupting the main narrative:

<Steps>
1. **Import the Aside:** Include `import { Aside } from '@astrojs/starlight/components';` at the top of your document.
2. **Choose a Variant:** Set the `type` attribute to `note`, `tip`, `caution`, or `danger` depending on severity.
3. **Keep it Concise:** Write short, direct warnings inside the aside block.
</Steps>

    **In Rich Text Mode:**
    1. Click the **+** (Add Block) button in the editor toolbar.
    2. Select **Starlight Aside / Callout** from the dropdown menu.
    3. Use the visual dropdown to select the **Type** (`note`, `tip`, `caution`, `danger`).
    4. (Optional) Enter a custom **Title**.
    5. Type your Markdown content into the **Callout Content** field.

    **In Raw Markdown Mode:**
    Use standard JSX tags: `<Aside type="caution" title="Optional Title">Your content here.</Aside>`

## Technical Writing Guidelines

When utilizing callouts in this knowledge base, adhere to the following stylistic rules:

* **Avoid Callout Fatigue:** Do not stack multiple asides directly on top of each other. If a page consists primarily of callouts, that information belongs in the main body text instead.
* **Keep it Concise:** An aside should rarely be longer than two sentences. If you need paragraphs of explanation, weave it into the main narrative.
* **Use the Right Severity:** 
  * Never use `danger` for simple tips just to grab visual attention. 
  * Reserve `danger` strictly for irreversible actions (e.g., deleting a database, exposing a secret key).
* **Write Action-Oriented Titles:** If you override the default title (e.g., "Note" or "Caution"), make the custom title descriptive and actionable (e.g., `title="Back up your files first"` instead of `title="Important"`).
