## What This Site Demonstrates

<CardGrid stagger>
  <Card title="Behind the Curtain Specs" icon="puzzle">
    Every UI component—steps, tabs, callouts, and file trees—is presented as a live rendered specimen alongside the raw MDX markup and Sveltia CMS configuration required to produce it.
  </Card>

  <Card title="Decoupled Git Authoring" icon="laptop">
    Demonstrates how Sveltia CMS provides a clean, visual content management interface for technical writers while preserving pure Markdown/MDX files and Git version control under the hood.
  </Card>

  <Card title="Automated Quality Gates" icon="approve-check-circle">
    Quality assurance treated as code. Pull requests are automatically validated using **Vale** for prose linting, **Lychee** for link integrity, and **Zod** schemas for frontmatter typing.
  </Card>

  <Card title="Modern Jamstack Delivery" icon="rocket">
    Built on **Astro + Starlight** for high performance, zero unnecessary client-side JavaScript, native dark mode, built-in search, and effortless static deployment via GitHub Pages.
  </Card>
</CardGrid>
